About the project

A scalable command-line system built with the Python standard library only: no frameworks, no external database.

Technical highlights

Three engineering ideas hold the project together.

1

Core object logic

An abstract Person class with Student, GraduateStudent and Teacher subclasses. Inheritance, encapsulated validation and polymorphic methods keep the code scalable.

2

Data persistence

Clean JSON files act as a lightweight local database, with atomic writes, auto-generated IDs and protection against corrupted files.

3

Error architecture

Layered exceptions (validation, record, storage) are handled in one central place, so bad input never crashes the app.

Features

Everything needed to run a small school's records from the terminal.

  • Add, view, update, delete and search students
  • Graduate students with thesis and advisor
  • Teacher records with subjects and experience
  • Record grades per subject with letter grades
  • Mean, median and standard deviation
  • Top performers and subject averages
  • Grade distribution and probation alerts
  • Input validation with friendly messages
  • Error log file for troubleshooting
  • Built-in demo data and unit tests

How polymorphism shows up

The same call, standing(), gives different results because each class defines its own rules.

class Student(Person):
    PASSING_MARK = 50.0
    HONORS_MARK  = 85.0

class GraduateStudent(Student):
    PASSING_MARK = 70.0
    HONORS_MARK  = 90.0

for s in students:
    print(s.standing())
